# Goblin Gold Rush 2.0 — Пепельная жила

Законченный браузерный уровень на HTML/CSS/JavaScript/WebGL2, использующий оригинальные утверждённые PNG. Никакой сборки для запуска не требуется.

## Запуск

Из корня проекта:

```sh
python3 -m http.server 8000 --bind 0.0.0.0
```

Откройте `http://localhost:8000/` в браузере с WebGL2. Для телефона используйте адрес компьютера в той же локальной сети и порт 8000. Игра рассчитана на горизонтальный формат 16:9. В ZIP готовая версия расположена в `game/`: запустите сервер из этой папки. Через `file://` запуск не поддерживается.

## Управление

Тап по сцене или пробел — короткий прыжок. Удержание — высокий. Гоблин бежит и атакует автоматически. Кнопка ярости / F — ярость при 100% заряда; длительность сохраняется вне боя. Прыжок разрывает Clash, а перед ударом босса земля подсвечивается. Кнопка паузы / Esc останавливает игру. Карточки улучшений также полностью останавливают симуляцию.

Три взаимоисключающих пути: Мясник бьёт группы и на третьем усилении расширяет удар до «Мясорубки»; Охотник усиливает одиночный урон и добивает; Чумной клинок накладывает яд, взрывается на третьем заряде и заражает соседей при смерти врага. Лечение даётся при улучшении и победе над стражем.

Уровень конечный: 27 000 единиц, два мини-босса и финальный страж. Проверенный маршрут занимает около 3–3.3 минут без времени выбора улучшений. Победа сохраняет золото в localStorage. За 80 золота можно купить +10 здоровья / +2 урона для следующих набегов. Первая победа открывает навык: +30% стартовой ярости. Очистка данных браузера сбрасывает прогресс.

## Исходники и ассеты

- `live/sim.js`: детерминированная физика 120 Гц, данные уровня, боёвка, прогрессия.
- `live/scene.js`: отрисовка, звук, управление, интерфейс, сохранения.
- `live/gl.js`: WebGL2-движок ref2game, MIT; лицензия в `third_party/`.
- `live/assets/`: 63 готовые PNG и manifest.json с происхождением и границами.
- `starter/`: исходные инструкции, 163 оригинальных файла, полный ASSET_MAP.json.
- `tests/`: проверки симуляции, браузера и покадровых ассетов.
- `frames/`: отчёты и снимки.

## Проверки

Node.js 24, Python 3 с Pillow, Playwright 1.62.1 и Chromium. Для установки тестовых зависимостей: `npm ci`. `tests/playwright-system.cjs` использует `/usr/bin/chromium`; можно задать `CHROMIUM_PATH` или использовать Chromium, установленный Playwright. `npm test` запускает 16 проверок симуляции, проверку 39 оригинальных кадров и 9 браузерных сценариев.

ref2game UI/anchors:

```sh
PLAYWRIGHT="$PWD/tests/playwright-system.cjs" node tests/ref2game-qa.mjs --only ui,anchors --out frames/qa-ui
```

Подробные результаты и ограничения: `TEST_RESULTS.md`. На физическом Android игра **не проверялась**. Дополнительные архетипы не генерировались; все три стража используют утверждённого рыцаря. Публичный хостинг и загрузка изменений на GitHub в эту поставку не входят.
