# Goblin Gold Rush — ready art starter for ref2game

This archive is a new-project SOURCE ART PACK for Codex, not an existing Godot project. All images are user-approved originals or assets recovered from the user's own game APK. NO new sprites generated.

1. Unzip in the new repository working directory.
2. Read `GAMEPLAY_AND_ASSET_RULES.md`.
3. Integrate original hero `assets/hero_approved/` and knight `assets/knight_approved/` first.
4. Browser game via ref2game WebGL2; no Godot import needed.
5. Preserve raw PNG and source reference so animation and cropping can be verified.
6. For limited Codex usage start with playable first 60–120 seconds, one miniboss, valid platform chain + combat; then add 2nd miniboss and final boss after confirming.

Note: Contains only graphical production assets, not decompiled Godot source scripts. This zip is suitable for GitHub web upload (single file <25MB), provided account access allows it.
